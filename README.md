# Qing Sun 的学术主页

[访问学术主页](https://sunnyqingsun.github.io/) · [GitHub 源码仓库](https://github.com/sunnyqingsun/sunnyqingsun.github.io)

GitHub Pages 从 `main` 分支的根目录发布。站内页面、照片和样式表使用相对链接。

- `index.html` 包含个人简介、研究兴趣、实验室和联系邮箱。右侧照片为 `assets/qing-sun.webp`。可在 `assets/site.css` 的 `.portrait-slot` 中调整照片宽度和边缘柔化范围 `--feather`。
- `research.html` 包含已发表论文、工作论文和在研项目。已发表论文列出作者和出版信息，点击 Abstract 可展开摘要。工作论文标题下列出合作者。
- 站内的 CV 链接直接打开 `Qing-Sun-CV.pdf`。更新简历时，用同名 PDF 替换这个文件即可。
- 日语首页、研究页和简历页分别是 `index-ja.html`、`research-ja.html`、`cv-ja.html`。CV 右侧的语言链接在同一页面的英日版本间切换。日语版 CV 直接打开 `Qing-Sun-CV-ja.pdf`。
- 英语和日语页面共用 `assets/site.css`。
